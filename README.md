# Darman_PLUST — Icons & Backgrounds

Collection of premium app icons and login screen backgrounds for the **Darman PLUST** healthcare application.

All assets generated with `fal-ai/z-image/turbo` (low-credit, non-Gemini, non-nano-banana model).

## Folder Structure

```
.
├── background/          # Login screen backgrounds (9:16)
│   ├── bg_dark_theme.png    # Dark theme — black/navy gradient
│   └── bg_light_theme.png   # Light theme — white/blue gradient
│
├── icons/               # Categorized icons (copies, for quick reference)
│   ├── accounts/        # User account selection icons
│   ├── finance/         # Billing & cashier icons
│   ├── reception/       # Waiting room / queue icons
│   ├── medical/         # Hospital, doctor, pharmacy, lab, etc.
│   └── general/         # Settings, notifications, reports
│
└── pngs/
    └── icons/           # All icon PNGs (1024x1024) — master copies
```
